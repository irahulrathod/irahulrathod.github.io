# Rahul Rathod Portfolio

A premium, responsive portfolio website for an experienced iOS Developer. Built with HTML5, CSS3 and vanilla JavaScript so it can be deployed directly to GitHub Pages.

## Features

- Apple-inspired dark visual system with subtle animation
- Responsive layouts for desktop, laptop, tablet and mobile
- Hero section with typing effect, CTA buttons and interface preview
- About, skills, experience timeline, featured projects, achievements, education and contact sections
- Intersection Observer reveal animations
- Animated achievement counters
- Accessible navigation, focus indicators and semantic HTML
- SEO meta tags, Open Graph, Twitter Card and JSON-LD

## Folder Structure

```text
portfolio/
  index.html
  css/
    style.css
  js/
    script.js
  images/
  assets/
  README.md
```

## How To Customize

1. Update links in `index.html` for GitHub, LinkedIn, email and phone.
2. Replace `assets/Rahul-Rathod-Resume.pdf` with the actual resume file.
3. Update project card links and descriptions in the Featured Projects section.
4. Replace or customize the Open Graph preview image at `images/og-preview.svg`.
5. Adjust colors in `css/style.css` under the `:root` variables.

## Deploy To GitHub Pages

1. Push the `portfolio` folder contents to a GitHub repository.
2. In GitHub, open repository settings.
3. Go to Pages.
4. Select the branch and root folder that contain `index.html`.
5. Save and wait for GitHub Pages to publish the site.

No build step is required.
